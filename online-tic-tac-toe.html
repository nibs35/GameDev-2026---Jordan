Online Tic Tac Toe

Play Online

Play with a friend over the internet. One person creates a room and shares the room code. The other person joins using that code.

1. Create a room

You will play as X. Share your room code with your friend.

2. Join a room

Enter the room code your friend shared with you. You will play as O.

Not connected. Create a room or join a friend's room to play online.

Both players need an internet connection. Keep this page open while playing.

New Game resets the board for both players. Only the connected players can make moves.

How it works

  1. Player 1 clicks Create Online Room.
  2. Player 1 copies and sends the room code to Player 2.
  3. Player 2 pastes the code and clicks Join Online Room.
  4. Player X goes first. Players take turns until someone wins or the board is full.

This is a peer-to-peer game using PeerJS. GitHub Pages can host the HTML file, while PeerJS's public signalling service helps the two browsers find each other. Network or browser restrictions may prevent a connection on some networks.
