About JavaScript Functions

What is a function?

Functions are used to organize code so it can be called and reused elsewhere. Information can also be passed to functions using parameters.

Good reference: W3Schools JavaScript Functions

Example 1: Function Code

This function reads a number, calculates its square, and returns a message with the answer. 

function myExampleFunction() {
    let myIn01 = parseFloat(
        document.getElementById('myText01').value
    );

    let mySum = myIn01 * myIn01;

    let myReply =
        myIn01 + ' * ' + myIn01 + ' = ' + mySum;

    return myReply;
}
