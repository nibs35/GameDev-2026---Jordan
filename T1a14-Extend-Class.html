About Classes and Inheritance

What is a class?

A JavaScript class is a template for creating objects. A class can contain properties and methods. Another class can extend an existing class to reuse its properties and methods.

Reference: W3Schools JavaScript Classes

Example 1: Creating an Animal Class

This example creates an animal with a name and an age. Click the button to create an animal named Snickers. 

class myAnimal {
    constructor(myName, myAge) {
        this.myName = myName;
        this.myAge = myAge;
    }

    myShow() {
        document.getElementById('myDiv01').innerHTML =
            'Hello ' + this.myName;
    }
}

Example 2: Extending a Class

The cat class extends the animal class. It inherits the name and age properties and has its own version of the myShow() method.
