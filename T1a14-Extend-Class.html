What Is a Class?

A JavaScript class is a blueprint for creating objects. For example, an animal class can store an animal's name and age and provide methods that let the animal do things.

This page demonstrates creating objects, calling methods, changing object properties, and extending one class with another.

There are 20 possible random names. Leave the name box empty to choose a random name, or enter your own!

How the Code Works

Class: A blueprint that defines the properties and methods of objects.

Constructor: Sets up an object's name, age, and birthday count.

Object: new myAnimal("Max", 5) creates an animal object.

Method: A function inside a class that an object can use.

Inheritance: myCat extends myAnimal allows the cat class to reuse features from the animal class.

Random names: JavaScript selects one of 20 names when you leave the name field blank.
