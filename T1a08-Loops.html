About JavaScript Loops

What is a loop?

A loop repeats a block of code multiple times. A for loop is useful when you know how many times you want the code to repeat. Loops can also use decisions to check conditions.

Reference: W3Schools JavaScript For Loops

Example Input Code

for (let myLoop = 0; myLoop < myMax; myLoop++) {
    // Your code here
}

The loop starts at zero and repeats until the loop counter reaches the maximum number.
