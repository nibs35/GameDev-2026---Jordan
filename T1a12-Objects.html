About JavaScript Objects

What is an object?

Objects are stored in named variables and contain properties that describe something. For example, a person object can store a first name, last name, age, and eye color.

Local and Global Variables

A global variable can be accessed from different parts of a script. A local variable is only available within the function or block where it is declared.

Why declare objects inside a script tag?

Declaring an object inside a script allows JavaScript to use its properties and methods. Using let or const helps keep variables organized and avoids unnecessary global variables.
