JavaScript Objects

JavaScript objects store related information using properties. This example creates a randomly generated person using a name, age, eye colour, and description. Each property is selected separately, allowing many different combinations.

Reference: W3Schools JavaScript Objects

How It Works

The generator uses arrays containing different names, ages, eye colours, and descriptions. JavaScript randomly chooses one value from each array and stores the results in an object. 

const person = {
    name: "Alex",
    age: 21,
    eyeColor: "Green",
    description: "Enjoys playing video games."
};

Every time the generator runs, it creates a new object using randomly selected properties.

Local and Global Variables

A global variable can be accessed from different parts of a script. A local variable is only available within the function or block where it is declared.

Remember: Use const when a variable does not need to be reassigned, and let when its value needs to change.
