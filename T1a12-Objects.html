How the Objects Work

Each generated person is stored in a JavaScript object. The object contains properties for the person's name, age, eye colour, and description. 

const person = {
    name: "Alex",
    age: 21,
    eyeColor: "Green",
    description: "Enjoys playing video games."
};

The program selects each property separately and then displays the resulting object on the page.

Local and Global Variables

A global variable can be accessed from different parts of a script. A local variable is only available within the function or block where it is declared.

Remember: Use const when a variable does not need to be reassigned, and let when its value needs to change.
