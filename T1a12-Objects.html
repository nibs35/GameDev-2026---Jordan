What Are JavaScript Objects?

A JavaScript object stores information using properties. For example, a person object can contain a name, age, eye colour, and a description.

Reference: W3Schools JavaScript Objects

How the Objects Work

Local and Global Variables

A global variable can be accessed from different parts of a script. A local variable is only available within the function or block where it is declared.

Remember: Use const when you do not need to reassign a variable, and let when its value needs to change.
